# Changelog

## 0.1.2

- Embed the complete offline interface in `main.js` so that community installers and BRAT need only the three standard release files.
- Add a standalone, reproducible source build, package checks, release documentation, and MIT license.
- Keep the plugin ID and planner data format unchanged for upgrades from 0.1.1.

## 0.1.1

- Add category deletion with explicit task transfer and preserved completion history.
- Remove stale automatically generated category calendars after deletion.

## 0.1.0

- Add monthly deadlines, custom category colors, priority markers, an undated backlog, daily completion records, handwritten progress, Markdown review export, and manual iCalendar exchange.
